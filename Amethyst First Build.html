About

What is Amethyst.gg?

Amethyst.gg is a Minecraft: Java Edition server project focused on skill-based gameplay. Whether you're chasing a faster time or a cleaner win, it's built for players who like to improve.

The server is currently in development. We're starting with a small set of gamemodes and polishing them before adding anything else.

Follow the roadmap below to see what's coming and when.
